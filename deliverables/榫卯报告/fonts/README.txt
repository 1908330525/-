Fonts included (recommendations) and usage instructions:

Recommended open-source fonts:
- Source Han Serif / 思源宋体 (https://github.com/adobe-fonts/source-han-serif)
- Source Han Sans / 思源黑体 (https://github.com/adobe-fonts/source-han-sans)

Usage:
1. Download the OTF/TTF files from the official repository links above.
2. Place the font files into this folder and also into the PPT fonts package if embedding is required.
3. For distribution, include a note about the open-source license (SIL/Open Font License).

Note: The repository does not currently contain binary font files. Please download them and upload to deliverables/榫卯报告/fonts/ if you want the full package committed here.
